## Design-system decisions

- Red Cross-inspired red accent (`--red`), navy operational surfaces, high-contrast text, 8px/12px control radii, visible focus rings, and mobile-first responsive layouts.
- Bilingual Filipino/English labels, plain-language boundary notices, minimum 44px touch targets, and reduced-motion support.
- Storyboard states: collapsed, expanded, completion, Hotline action, disclaimer, and keyboard focus.
- Payment states: route selection, exact account copy rows, private QR preview, reference entry, receipt preview, validation error, retry, verification pending, verified, and replacement requested.
- Admin states: password login, aggregate dashboard, queue filters/search/sort/pagination, minimum-necessary case review, signed evidence viewer, decisions, confirmation, empty/loading/error states.
